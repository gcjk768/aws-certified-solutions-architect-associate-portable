# SAA-C03 community question sources

Checked 2026-11-10. Build: `python -I import_community.py` (validate only: `--check`). Output: `community_bank.csv` (520 rows).

## Used
- https://d1.awsstatic.com/training-and-certification/docs-sa-assoc/AWS-Certified-Solutions-Architect-Associate_Sample-Questions.pdf · © AWS, official free sample · used (10): credited as "AWS official SAA-C03 sample questions", with AWS's explanations.
- https://github.com/BerkayCakibey/aws-saa-tips · MIT · used (325): README says the questions are original (AI-assisted, author-reviewed), not from dumps or other banks; each has an explanation and doc links. The source puts most answers first, so the import shuffles options in a fixed order per question.
- https://github.com/el-amin-dev/AWS-mock-exams · MIT · used (125): README says the bundled mocks were "written from scratch" and are "not real exam questions or dumps"; there is a per-option explanation.
- https://github.com/cuic19053-hue/learnai · Apache-2.0 · used (60): AI-generated SAA-C03 sets v1 and v2 with explanations; the source always puts the answer at A, so the import shuffles them. The questions are short and a few distractors are weak.
